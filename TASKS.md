- [ ] Authentication

- [ ] Complex RAG
- [ ] Large external datasets
- [ ] Unnecessary integrations

## Constraints

- [ ] Keep the implementation suitable for a 6-hour hackathon
- [ ] Use one primary agent and a small number of tools
- [ ] Avoid unnecessary dependencies and external APIs
